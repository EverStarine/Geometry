# 几何学

《几何学》是 R. EverStarine 编写的五卷本中文数学教材。目录、选读范围、证明责任与阅读条件以根目录的 [几何学计划纲要](几何学计划纲要.md) 为准。第一卷二十章正文及附录 A—E 已形成含证明、例子及完整习题解答的初稿；附录 B 的晶体群与格堆积增补，以及附录 E 的反射群、正多胞形、凸多面体刚性与剪刀合同专题均已写完。第二卷第1—3章也已形成初稿，其中第1章包含4节、16个小节及13道习题，第2章包含4节、17个小节及14道习题，第3章包含4节、16个小节及15道习题，各题均附完整解答。第一卷前言、后记及前两编导言尚待撰写，第二卷其余部分及第三至第五卷仍保留写作框架。编、章、节与规划条目依纲要组织。

五卷各自独立编号；章号跨编连续，附录从 A 重新开始。星号是章、节的选读标记，附录本身即为选读。节内条目使用 `1.1.1` 形式的小节编号，并进入总目录与 PDF 书签；附录主题组和子条目分别使用 `A.1`、`A.1.1` 形式的编号，同样进入目录与书签，便于查找和跨章引用，并与代数学项目保持一致。尚未撰写的内容统一显示“待撰写”，方框只用于本章目标和本章小结。各卷可以按纲要给出的具体知识条件分别学习，不把卷次当作必须依次通读的要求。

## 项目结构

```text
几何学计划纲要.md             原始总纲，保留在根目录
Book1/ … Book5/              独立主文件、书前书后、编章与附录
Shared/                      共同样式、数学宏、索引样式和 References.bib
写作规范/                    写作、术语、排版、书目与操作规范
工作记录/                    当前审核状态、跨卷引用与资料目录
参考文献原文件/              本地第三方资料，不提交原文件
scripts/                     编译和结构核验工具
build.ps1                    根目录构建入口
tmp/build/BookN/             每卷独立构建缓存
```

书写规范见 [写作规范](写作规范/写作规范.md)，统一符号见 [术语规范](写作规范/术语规范.md)。五份规范共同适用[总则](写作规范/写作规范.md#总则)：规则逐条说明原因，原因失效则相应规则失效；工作记录只为后续接续、定位、核验和决策服务，以减少重复维护和查找成本。第一卷及第二卷已写部分的状态详见 [审核进度](工作记录/审核进度.md)，正式审核完成数为 0。五卷现有 142 章、24 篇附录；专题增补的写作顺序、先修与证明任务见 [专题扩充写作计划](工作记录/专题扩充写作计划.md)。专题增补中的第一卷 B.4 与附录 E 已形成初稿；附录 E 共5节、24小节及16道有完整解答的习题，其余新增位置待撰写；编译结果与审核状态分开说明。

## 编译与检查

在项目根目录构建单卷，例如第一卷：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Book 1
```

将 `1` 改为 `2` 至 `5` 即可选择对应卷；省略 `-Book 1` 构建五卷。编译使用现有 TeX Live，按需运行 XeLaTeX、Biber 与三类索引处理，再完成交叉引用。构建缓存写入 `tmp/build/BookN/`，成功后更新该卷预览与根目录 `BookN.pdf`。这些 PDF 是框架或工作稿预览，不表示正文完成或审核通过。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Check-Outline.ps1
```

结构检查只核对纲要、标题、标记、标签和输入链，不能代替正文完成度检查或数学审核。格式核验以源码和编译日志为主，只在有具体疑点时查看相关页面。操作细节见 [工作流程说明](写作规范/工作流程说明.md)。

生成 PDF 后可检查书签的标题、编号、选读星号、层级和跳转页：

```powershell
python -B .\scripts\Check-PdfBookmarks.py
```

该工具使用已有的 `pypdf`；若其不能正确提取嵌入中文字体，封面文字检查会尝试已有的 PyMuPDF。它只提取封面文字，不渲染页面，也不构成数学审核。两个检查工具均可用 `-Book 1` 选择单卷。
