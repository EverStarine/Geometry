# 《几何学》LaTeX 与排版规范

本文件管理五卷的文件接口、编号、引用与成品版式，遵守[总则](写作规范.md#总则)。数学内容、术语和书目分别由[《写作规范》](写作规范.md)、[《术语规范》](术语规范.md)和[《书目维护注意事项》](书目维护注意事项.md)管理；构建与检查步骤见[《工作流程说明》](工作流程说明.md)和[README](../README.md)。

## 1. 文件与共享接口

| 规则 | 原因 |
|---|---|
| 五卷分别以 `Book1/Book1.tex` 至 `Book5/Book5.tex` 为唯一主文件，独立生成 PDF；不另设合订本主文件。 | 独立入口使每卷的编号、书目、索引和构建产物彼此隔离，也允许只构建受影响卷。 |
| 主文件定义卷元数据并装配书前、正文、附录和书后；内容写在相应的章、节文件中。 | 清楚的输入链便于定位缺失文件和调整全卷顺序。 |
| 共用宏、字体、颜色、页面与环境样式放在 `Shared/Preamble.tex`，正文西文字体规则放在 `Shared/TextLetterFont.tex`，索引样式放在 `Shared/geometry.ist`；不得在各卷复制或局部改写同一套定义。 | 单一共享实现可防止五卷版式分叉，也使共享修改能够统一验证。 |
| TeX 源文件使用 UTF-8；子文件保留指向本卷主文件的 `% !TeX root = ...` 注释。 | 统一编码避免中文和数学字符损坏；根文件注释保证从子文件编辑时仍调用完整文档。 |
| TeX 普通叙述按自然段组织源码，不按固定行宽或一句一行机械折行；标题、环境边界、列表项、行间公式与必要注释单独分行。环境、列表、分段公式及宏定义内部按层级用 Tab 缩进，不用缩进模拟成品中的空白。 | 连续语句应便于阅读和编辑；不必要的换行可能在宏边界变成可见空格，结构化分行与一致缩进则能显示真实层次。 |
| 文件装配层级为“主文件 → 编／附录总入口 → 章／附录章入口 → 节文件”；正文按节分文件，小节写在所属节文件内。 | 固定层级便于核对纲要、目录和输入链，也避免产生大量只有数行的碎片文件。 |
| 图片与可复用图表源文件放在卷内 `Figures/`、`Tables/`，构建缓存和临时预览放在 `tmp/`。 | 正式输入与可重建产物分离，后续工作可以直接找到应修改和应保留的材料。 |

## 2. 路径、编号与标签

| 规则 | 原因 |
|---|---|
| 正文路径使用 `BookN/PartPP/PartPP.tex`、`BookN/PartPP/ChapterCC/ChapterCC.tex`、`BookN/PartPP/ChapterCC/SectionCCSS.tex`；`BookN` 不补零，编、章、节号各用两位数字。 | 固定宽度的名称按目录排序即为阅读顺序，也让检查工具能够明确识别层级。 |
| 附录总入口为 `BookN/Appendices/Appendices.tex`，各篇使用 `AppendixA/AppendixA.tex` 等文件；纲要已有主题组和组内要点分别排为编号节、小节，不额外增造内容层级。 | 按已有内容分组编号便于读者检索，保留纲要层次则避免为排版制造空层级。 |
| 每卷章号跨编连续；每卷附录从 A 重新开始，只显示字母，不带卷号。 | 这与现有目录及引用体系一致，也避免同卷出现重复正文章号。 |
| 编、章、编号节、小节、附录章及实际需要引用的数学对象设置标签；证明、解和证明概要不设编号标签。 | 有稳定编号的对象才能被准确回引，无编号证明环境没有独立序号。 |
| 标签使用含卷号的稳定语义键，不把可能改动的完整标题写入标签；新增正文小节标签采用 `gN:subsec:0101:01` 形式，附录节、小节分别采用 `gN:sec:A01`、`gN:subsec:A01:01` 形式。对象改名或移动但身份未变时保留原标签。 | 卷别与初始位置便于定位，保留稳定标签可避免标题或顺序调整使全书引用和后续工作线索失效。 |
| 标签前缀采用 `gN:part:`、`gN:ch:`、`gN:sec:`、`gN:subsec:`、`gN:app:`、`gN:thm:`、`gN:def:`、`gN:lem:`、`gN:prop:`、`gN:cor:`、`gN:claim:`、`gN:rem:`、`gN:exm:`、`gN:ex:`、`gN:eq:`、`gN:item:`、`gN:fig:`、`gN:tab:`、`gN:alg:` 等；新增类型使用不冲突的简称。 | 前缀能直接标明卷别和对象类型；例与习题分用 `exm`、`ex` 可避免语义混淆。 |
| 普通章的 `\label{...}` 紧随标题命令，之后调用 `\BookChapterNumber{同一标签}`；其他标题和数学对象的标签紧随标题命令或环境开头。 | 标签靠近对象可减少错绑；`\BookChapterNumber` 保存被引章的汉字章号，避免跨章引用时误取当前章号。 |
| `\OptionalChapter{章名}{标签}`、`\OptionalSection{节名}{标签}` 已设置标签，不再另写同一 `\label`；选读章后仍调用 `\BookChapterNumber{同一标签}`。 | 共享宏已经负责标题标签，重复设置会引入重复标签提示；汉字章号仍需单独保存。 |

## 3. 页面、页眉与书签

| 规则 | 原因 |
|---|---|
| 书名页用 `\MakeBookTitle`，目录用 `\MakeBookContents`；书名、卷次、作者、日期和稿件状态通过卷元数据传入，不在单卷重做字号或间距。 | 共享入口使五卷的封面、目录和顶级书签保持一致。 |
| 书名页后保留一张计入页序但不显示页码的空白页。 | 双面成书时可使序言从奇数页开始，并保持现有物理页序。 |
| 书前使用小写罗马页码，正文与附录使用阿拉伯页码，书后重新使用小写罗马页码。 | 不同区域的页码体系区分正文与辅助材料，也与现有五卷入口一致。 |
| 每编使用 `\BookPart{编名}{标签}` 和 `\BookPartGuide`，本编导读列入所属编下的总目录；编题页从奇数页开始，其后保留一张真正的空白页。 | 共享命令同时处理分页、目录、标签和书签，避免各编手工实现后出现差异。 |
| 普通正文偶数页眉显示页码与章标题，奇数页眉显示进入本页前最后有效的节标题与页码；新节和习题的标记从后续页生效。 | 页眉应定位正在阅读的跨页内容，不应因页末刚出现新标题而提前改变。 |
| 编题页与章首页不显示页眉横线，页码置于页脚中央；真正的空白页不显示页眉、页脚和可见页码。 | 特殊页面需要与连续正文区分，空白页也不应残留上一单元的标记。 |
| 序言、编导读、后记、参考文献、索引等无编号章级单元的后续页显示该单元自己的页眉。 | 沿用上一正文节的页眉会给出错误的阅读位置。 |
| 书名页、目录、附录总入口和书后各单元保留顶级 PDF 书签；共享命令已经生成的目录项和书签不得再手写一遍。 | 唯一的导航树便于查找，重复入口会制造同名节点或错误层级。 |
| 有编号的书签显示与正文一致的编、章、节、小节编号及选读标记；无编号单元不补虚构编号。 | 书签应与目录和正文位置对应，读者才能按现有编号查找。 |

## 4. 标题、选读与占位

| 规则 | 原因 |
|---|---|
| 纲要中的节内条目使用 `\subsection{...}` 排出 `1.1.1` 形式的编号小节，并列入总目录和 PDF 书签；共享层采用 `secnumdepth=3`、`tocdepth=2`，与代数学项目一致。节首导语和条目后的说明段不另造标题。 | 编号、目录和书签共同帮助读者直接查找具体主题及跨章回看，沿用前作设置也使两套教材的导航方式一致。 |
| 附录主题组用 `\section{...}`，组内要点用 `\subsection{...}`，分别显示 `A.1`、`A.1.1` 形式的编号，并列入总目录和 PDF 书签。 | 附录的背景知识和补充论证也需要被正文准确回引，统一编号与导航可减少读者反复翻找。 |
| 纲要中的选读章、节使用 `\OptionalChapter`、`\OptionalSection`；标题中不手写星号，也不用 `\chapter*`、`\section*` 取消原有编号。 | 星号表示选读范围而不取消原有位置，共享宏能够同步正文、目录、页眉和书签。 |
| 附录天然作为补充阅读，不加选读星号；每卷只设一个由 `\BookAppendixPart` 建立的无编号“附录”编，各附录章挂在其下。 | 单一入口保持目录与书签层级清楚，额外星号不能增加导航信息。 |
| 章末习题统一使用 `\BookExercises`，每章只生成一个“习题”目录项和书签；选做题用 `optionalexercise`，不再手写星号或附加“综合”“进阶”等泛化类别。 | 共享入口同时处理目录和页眉；题号星号已能区分选做范围，重复标记会挤占题名周围的阅读空间。 |
| 标题中的数学符号使用数学模式，并用 `\texorpdfstring` 提供可读的书签文本，例如 `\texorpdfstring{\(L^p\)}{Lᵖ}`。 | 正文公式与 PDF 书签采用不同文本机制，直接把数学命令写入书签可能丢字或产生警告。 |
| 当前标题中 `\bar{\partial}` 的书签备选使用 `\={∂}`，如 `\texorpdfstring{\(\bar{\partial}\)}{\={∂}}`；遇到已复现的希腊字母辅助文件回读问题时，使用共享层已有的 `\GeometryPdfAlpha` 等对应宏。只有同类问题确实存在时沿用这些规避；工具更新后若不再出现原问题，就不再据此强制特殊转写。 | 当前组合字符和部分 Unicode 数学字符在辅助文件写入、回读时可能触发反复标签变化提示；规避只为解决实际的编码问题，不能成为脱离工具条件的永久字形规则。 |
| 方框仅用于 `learninggoals` 的“本章目标”和 `chaptersummary` 的“本章小结”；摘要、编导读、正文、习题、书前书后和附录采用普通排版，不因共享层保留兼容环境而启用额外方框。 | 两类方框突出章的学习入口与收束，与前作保持一致；其他位置加框会削弱这种层次。 |
| 尚未写出的摘要、目标、引入、小节内容、小结、习题、书前书后文字及空书目、空索引，统一写普通文字“待撰写”，不额外添加提示框或重复状态说明。 | 明确的占位便于继续写作；重复提示与装饰框不能提供更多可用信息。 |

## 5. 数学环境与列表

| 规则 | 原因 |
|---|---|
| 定义、例、命题、引理、定理、推论、断言、猜想、开放问题和注记使用与其数学职责相符的环境，共用“章.节.本节流水号”，保留各自引用类型；未分编号节的附录显示 `A.1` 等，不出现 `A.0.1`。 | 共享流水号反映阅读顺序，独立类型让引用名称准确；附录尚未进入编号节时，回退格式避免出现没有对应内容层级的零级编号。 |
| 习题使用独立计数器，每章从 1 开始，显示“章号.章内序号”；附录习题显示 `A.1` 等，普通题与选做题共用该序列。 | 习题增删不应扰动正文结果编号，同章题号也应连续可查。 |
| 定理、命题、引理、推论等数学环境的可选标题只放简明数学名称或主题，编号由环境生成；不在标题中标注“外部结果”“引用”“不在此证明”等来源、证明状态或长解释，相关引用及证明范围在陈述后的正文中说明。 | 标题便于识别结果，来源和证明范围则需要上下文；分开放置可避免标题冗长，同时保留可查依据。 |
| 普通习题不设括号副标题；只有重要或著名且简短名称确有助于识别、回引的题目才保留题名。题目的条件与任务完整写入题干，不依赖副标题补足。 | 题号与题干通常足以定位内容，逐题重复概括会增加阅读负担；少数有辨识作用的名称则有助于查找，完整题干可避免省略标题后丢失条件。 |
| `proof`、`solution`、`proofsketch` 不编号，终止符由环境生成，不手写“证毕”或额外方块；不把数学环境用于普通过渡句或编写状态。 | 证明与所证结果保持从属关系，自动终止符可避免重复，环境类别应保留数学含义。 |
| 定理类中文正文使用共享楷体，非数学西文保持正体；证明、解和证明概要只有标题用楷体，正文用普通正体，数学字体不随文字环境改变。 | 字形承担稳定的层级提示，同时避免西文或公式被意外倾斜。 |
| 普通有序列表三层依次使用 `1.`、`1)`、`a)`；等价命题用 `equivalences`，两层依次为 `I.`、`i)`；不使用四层以上嵌套。 | 不同列表语义具有可辨认的编号，限制嵌套可保持版心和引用关系清楚。 |
| 习题分问用 `enumerate`；长段解答在 `solution` 中用自然段，以对应分问号开头，不用列表包住整段论证；短项确需逐条列举时仍可用列表。 | 分问号对应便于查阅，列表缩进则会挤窄长段文字和行间公式。 |
| 需要引用的列表项在 `\item` 后立即设 `\label`，并用 `\itemref{...}` 引用。 | 该接口使括号和编号整体成为链接，列表增删后也无需手改序号。 |

## 6. 交叉引用与链接

| 规则 | 原因 |
|---|---|
| 定理类、图、表和算法优先用 `\cref`，公式用 `\eqref`，不在类别名后拼接裸 `\ref`。 | 类型和编号由同一链接生成，可避免名称与目标不一致，也扩大可点击区域。 |
| 编号章、节、小节和附录章分别用 `\chapref`、`\secref`、`\subsecref`、`\appref`；附录内的编号节、小节也用 `\secref`、`\subsecref`。宏外不重复“第”“章”“节”等字样，并列引用每项均使用相应宏。 | 共享宏已包含类别和间距，每个目标都应可点击，并在结构调整后自动更新。 |
| 习题入口等确实无编号的标题不用编号引用宏；需要定位时写明所属编号章、节或附录章及标题文字。 | 无编号标题没有独立序号，编号宏会误取最近的计数器，制造并不存在的编号。 |
| 章、节、小节引用用于阅读导航；证明中的关键调用指向具体定理、命题、引理、推论或公式。 | 章节范围不能说明实际使用哪条结论，也不能代替对其假设的核对。 |
| 引用宏与相邻中文或全角标点之间不加源码空格或 `~`；因换行产生不需要的空格时用行末 `%` 抑制。 | 共享宏已经处理中文间距，人工空白会使成品出现不一致的间距。 |
| 独立 PDF 之间用明确的卷名、位置和结果名称作文本引用，不用卷内引用宏伪造跨卷链接；跨卷结果的使用条件按《写作规范》处理。 | 卷内标签不能解析到其他 PDF；数学依赖的有效性也不能由排版链接保证。 |
| DOI 和网页采用标准 URI 链接，不加入强制新窗口的 PDF JavaScript。 | 标准链接在不同阅读器中兼容性更好，也允许读者自行决定打开方式。 |

## 7. 段落、字体与公式

| 规则 | 原因 |
|---|---|
| 用真实空行结束段落，不用手工空格或固定 `\hspace` 模拟首行缩进；摘要、目标及其后正文也遵守此规则。 | TeX 只有真正结束段落后才能恢复缩进，手工位移会随字体和版心变化而失准。 |
| 两个连续普通叙述段落先以空行分段，再在两段之间独立写 `\ProseParagraphBreak`；标题、列表、公式、定理、图表、引文等边界及 `proof`、`solution`、`proofsketch` 内不用该命令。 | 该接口只补充普通散文段距，在结构边界叠加会产生多余空白。 |
| `chaptersummary` 中连续的普通段落沿用 `\ProseParagraphBreak`；单段小结不为形式统一而拆段。 | 小结与正文采用相同散文节奏，但段落划分仍应由实际内容决定。 |
| 正文、证明和解答通常以自然段衔接，不给普通段落添加密集的 `\textbf{...}` 小标题；长篇复杂论证确需提示阶段时才保留少量小标题。 | 小标题应帮助把握论证结构，密集使用会盖过推理并制造多余层级。 |
| `\term`、`\textbf` 等行内文字宏与相邻中文、中文标点之间不加源码空格或人为换行；必须跨行时用行末 `%` 抑制空白。原文中的词间空格、公式与西文的必要间距按各自规则保留。 | 字体切换和可选参数边界可能使换行被排成额外词间距，破坏连续中文的字距；无差别删除空格又会粘连西文或改变源码含义。 |
| 诗歌与短引文用 `quote` 或 `poemquote`，出处用 `\quoteattribution{...}`，不用手工空格模拟居中或右对齐。 | 共享环境统一处理字形、边距和对齐，手工空格在换行后容易错位。 |
| TeX 行内公式用 `\(...\)`，行间公式用 `\[...\]` 或标准公式环境，不使用 `$...$`、`$$...$$`；原始 Markdown 纲要保留既有定界符。 | 统一的 LaTeX 定界便于检查配对，也避免 `$$` 绕过文档类的公式设置；纲要不是 TeX 输入，无需为此改写。 |
| 行间公式只在后文确需引用时编号并设标签。 | 不被调用的序号没有导航作用，还会打断阅读。 |
| 首次绑定后文复用的记号可用 `\coloneqq`；既有等式、局部假设和临时命名仍用 `=`，源码不写 ASCII `:=`。 | 定义号应区分实际的记号绑定与等式，机械替换会增加符号噪声。 |
| 行内公式与相邻正文保留正常源码空格，标点前不强加空格；引用宏按上一节专门规则处理。 | 中西文和数学间距应由共享排版统一计算，人工叠加会造成空白不均。 |
| 数学符号与 `\text{...}` 叙述之间按语义使用显式数学间距，短条件可用 `\;`，独立说明可用 `\quad`；固定后缀、运算符、上下标名称和纯文字图标签不机械加空格。 | 数学模式中的普通源码空格通常不形成间距，明确区分公式与叙述才能避免文字紧贴符号。 |
| 粗正体字母或数字用 `\mathbf` 或 `\symbfup`，粗斜体用 `\symbfit`，不能仅凭 `\boldsymbol` 的名称断定当前字体提供了所需粗字形。 | 命令必须与共享 Unicode 数学字体的实际字形匹配，避免源码意图与成品不一致。 |
| 固定运算符及群名用已有命令或 `\operatorname` 排为正体，例如 `\operatorname{SO}(3)`、`\operatorname{GL}(n)`；反复使用的复合符号确需共享定义时集中到共享层。微分、曲率、Laplace、辛与 Floer 等记号的数学含义遵守《术语规范》，不能为统一字形而改变方向、正负号或运算含义。 | 正体将固定名称与变量相区别，集中定义可统一字形和间距；排版调整没有改写数学约定的权限。 |
| 表示微分的 `d` 统一写为 `\mathrm{d}`，包括导数、映射的微分、外微分、复形的微分及积分测度，例如 `\frac{\mathrm{d}f}{\mathrm{d}t}`、`\mathrm{d}f`、`\mathrm{d}x`、`\int f(x)\,\mathrm{d}x`；作为维数、距离函数、参数或普通变量的 `d` 仍用斜体，`\partial` 保持原符号。 | 微分是固定运算，正体可与变量区分；同一字母还承担其他数学含义，按含义处理可避免误改维数、距离与参数。 |
| 切空间、切丛和余切构造的 `T` 统一写为 `\mathrm{T}`，例如 `\mathrm{T}_pM`、`\mathrm{T}M`、`\mathrm{T}_p^*M`、`\mathrm{T}^*M`；切映射、复化及型分解、相应切层沿用此字形。表示切向量、一般张量、挠率、运输映射、环面、周期等其他对象的 `T` 保留斜体，张量空间或张量丛的独立记号 `T^r_s` 也不据字母机械改写。标题、正文、习题、图表及索引遵守相同的语义区分。 | 正体突出切与余切这一固定构造，便于与同页出现的张量、向量及映射变量区分；同一字母可承担不同含义，统一构造的字形不应抹去这种区别。 |
| 表示固定微分运算的 `D` 统一写为 `\mathrm{D}`，包括欧氏导数、方向微分、沿曲线求导和外协变微分，例如 `\mathrm{D}f`、`\mathrm{D}_X Y`、`\mathrm{D}_tV`、`\mathrm{D}_A\xi`；任取的导子、待比较的候选算子，以及分布、区域、行列式等变量仍写斜体 `D`。单字母 `T`、`D` 的此类字形调整使用 `\mathrm`，不为改成正体额外引入 `\operatorname` 的运算符间距。 | 固定求导记号与既有正体 `\mathrm{d}` 协调，使读者易于识别运算；任取导子虽然是数学上的算子，符号仍承担对象变量的角色。只调整字形而保持原有数学间距，可避免无关的排版变化。 |
| 定界符按内容高度选择能完整包围内容的最小合适尺寸，可用 `\left...\right`；自动尺寸不合适时适度选用 `\bigl`、`\Bigl` 等，不按嵌套层数机械放大。 | 大小应服务于结合范围的辨认，过大的括号会破坏公式比例。 |
| 行内分式采用易读的尺寸；分式使行距或横向排版拥挤时，将整式移为行间公式。 | 读者需要同时辨认分子分母并保持稳定的行距，不能仅以公式未溢出作为判断标准。 |
| 相邻绝对值、范数或基数的乘法容易形成混杂竖线时写明 `\cdot`；集合条件线和整除号紧邻这些竖线时，按实际高度适度放大并保留对应间距，普通位置仍用 `\mid`、`\nmid`。 | 不同含义的竖线需要直接可辨，局部消歧不应扩展成统一放大全部竖线的规则。 |
| 系数乘以函数值或微分形式而容易与求值、求导混淆时写明乘号；普通无歧义单项式与积分测度沿用惯常写法。群作用、函数复合和算子合成须核对本处定义后再调整排法。 | 空格不足以消除运算歧义，但插入乘号也不能改变原运算或把积分测度误写成独立乘法约定。 |
| 行内映射用 `\rightarrow`、`\mapsto`，行间映射用 `\longrightarrow`、`\longmapsto`；集合构造式在定界符、元素与条件间保留适度数学间距。 | 长箭头适于独立公式，适度间距能帮助辨认集合构造中的不同成分。 |
| 人物和译名脚注放在完整中文词组或句末标点后，不紧贴公式、数字或拉丁字母；标题首次出现的姓名需要注释时，移至后续首次合适的正文，人物生卒年用短横线连接。 | 脚注标记紧贴变量时容易被误读为上标，移动参数中的脚注还可能污染目录和书签；短横线也比偏高的全角波浪号整齐。 |

## 8. 图、表与算法

| 规则 | 原因 |
|---|---|
| 需要在正文中引用的图、表和算法设置编号、标题和标签；证明内部的小型交换图可保持非浮动。 | 正式对象需要稳定引用，局部推导图浮动后则可能远离解释。 |
| 图、表、算法的完整编号分别为“图 X-n”“表 X-n”“算法 X-n”，其中 `X` 为章号或附录字母，`n` 在章内递增；类别名与编号之间采用共享不可断空格，整串作为同一链接。 | 共享格式保证题注、目录和正文引用一致，也避免编号断行或只让局部字符可点击。 |
| 长题注给目录提供短题名，例如 `\caption[短题名]{短题名。补充说明}`。 | 图表目录需要便于扫描，长解释宜留在图表附近。 |
| 图、表、算法目录只在该卷已有相应正式对象后接入，使用 `\MakeBookListOfFigures`、`\MakeBookListOfTables`、`\MakeBookListOfAlgorithms`；不列入总目录，不另建 PDF 书签，各自从下一页开始且标题与条目同页，不补单双页。 | 空目录没有导航价值，额外题页、空白页与书签也会增加无用层级。 |
| 表格按内容分配列宽，优先使用已加载的 `booktabs`、`longtable`、`tabularx` 等接口，不仅凭“无 Overfull”判定可读。 | 表格即使未溢出，也可能列宽失衡、文字拥挤或阅读顺序不清。 |
| 交换图使用 `tikzcd`，几何图优先保留可编辑源文件，并核对箭头方向、复合次序及交换、反交换或其他图示关系。 | 可编辑源便于修改，但错误的方向和数学关系通常不会触发 TeX 报错。 |
| 满足《写作规范》内容要求的算法使用简短程序名作题名，内部使用 `algorithmsteps` 接口列明输入、输出与编号步骤。 | 题名便于直接识别算法，共享接口使步骤结构一致并支持后续引用。 |
| 新增或大改几何图、交换图与大型表格后，以源码和 TeX 日志检查为基础，只定向查看相关页面的缩放、跨页、文字辨识和阅读顺序。 | 空间关系不能完全依靠日志判断，但批量渲染无关页面不能便利后续修改。 |

## 9. 书目、索引与书后输出

| 规则 | 原因 |
|---|---|
| 书目使用 `biblatex + biber` 与 `Shared/References.bib`，正文用 `\cite`，书后用 `\PrintBookBibliography`；不用 `\nocite{*}` 把全库填入单卷。 | 每卷只应列实际引用的资料，共享入口也能正确处理尚无引文的框架。 |
| 书目数据库的字段、版本与来源按《书目维护注意事项》维护，不在本文件另立数据规则。 | 专门文件统一管理数据真实性与字段，避免两套规则发生漂移。 |
| 参考文献中的非数学西文使用共享 Pagella 正体并保留必要粗细，书名、中文和标点不由书目样式自动改成斜体，数学内容仍用全书数学字体；不通过改写数据库字段实现字形变化。 | 字体属于输出样式，共享层调整可保持一致而不损伤真实书目信息。 |
| 中文、外文和符号分别写入 `chinese`、`foreign`、`symbols` 三类索引，分别运行处理器，统一使用 `Shared/geometry.ist`。 | 三类条目的排序逻辑不同，合并处理会破坏各自的次序。 |
| 索引收词、主称、别称与实际定位遵守《术语规范》；排版使用共享索引宏，不在卷内手写输出，不从纲要生成虚假页码或未经落实的条目。 | 术语规则决定收什么，实际正文决定定位，共享层负责排版，三者不能互相替代。 |
| 索引采用共享的小号双栏样式，不在卷内局部重设页码与分隔格式；书后通过 `\PrintBookIndex` 读入真实索引，空索引保留入口但不得复用旧 `.ind`。 | 一致的版式便于扫描，旧索引可能包含已删除词条或错误页码。 |
