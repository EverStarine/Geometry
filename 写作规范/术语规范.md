# 《几何学》术语、数学约定与索引规范

本文件管理中文主称、符号约定与索引，适用共同的 [总则](写作规范.md#总则)。根目录 [几何学计划纲要](../几何学计划纲要.md) 是既有术语和全书符号的依据；下列条款按实际适用范围从代数学项目抽取。

## 1. 术语与辨析

| 规则与适用范围 | 原因 |
|---|---|
| 沿用几何纲要及作者指定的中文主称；同一概念只设一个主称，有依据的异名在首次定义或必要辨析处说明，后文仍用主称。 | 主称统一可防止标题、索引和跨卷引用漂移，保留异名则便于对照文献。 |
| 新术语先核对定义、中文专业用法与来源；普通数学实词采用有依据的中文主称。尚未核定稳定中译时，用准确的中文描述交代实际对象，并在首次附原文供查证，不把字典直译或临时简称冒充通行定名。 | 临时译名不能冒充已获认可的术语，保留原文更便于复核和修正。 |
| 中文主称与异译需要出处时，分别核对，优先使用通行专业教材或正式公布的规范名词；证据只到摘要或目录时只说明实际可见的范围，不编造页码和核读经历。 | 异译有来源不代表主称已有依据，英文定义有依据也不代表中文用名已经审定。 |
| 正文和标题优先用中文主称；人名、专名、标准缩写和数学记号按通行写法保留，类别词和句法连接用中文。 | 中文有利于连续阅读，保留专名原文兼顾检索，明确连接词可避免对象与性质的关系含混。 |
| 几何纲要中的“结点”“粘合”等用字保持不变，不按代数学项目的“节点”“黏合”自动替换；人物姓名、标准缩写和书目原题名不作词形替换。 | 两项目已有各自约定，照搬前作的局部用字会破坏本项目内部一致性，也可能歪曲来源。 |
| 引用他人原话或原题名时保留该来源的实际用语，必要时另注本书主称。 | 忠于来源与统一本书叙述是两项不同职责，不能靠改写引文混为一谈。 |
| 正文叙述数学家时，已有明确中文本名者用中文本名，其余保留原文姓名及必要的统一转写，不附中文音译；地名、机构等专名同样保留原文，不据此改动书目署名。 | 原名便于检索，并避免人物、定理和书目出现互不对应的名称。 |
| 每卷在数学叙述中首次提到数学家时，脚注保留母语原名及必要转写、生卒年、国别与一两项主要成果，正文已有内容不重复；仅列作参考书作者者不在此列。普通简介不为每项信息堆积书目条目，具体引语或有争议的史实仍注明来源。 | 各卷可分别阅读，必要背景应就近提供，书目同时应集中支持实际数学内容和确需考据的事实。 |
| 日本数学家人物脚注保留日文汉字原名，随后注明假名、罗马音和生卒年，再简述国别与成果；不重复列写汉字姓名或另加中文音译。 | 原字形、读音和检索形式各有作用，重复音译不能增加辨识信息。 |
| 默认对象与正式结果的假设分开：全书默认约定不能成为定理关键条件的唯一出现位置；实维数、复维数与相对维数分别说明。 | 结果可能脱离上下文被引用，维数类型和附加条件会实质改变结论。 |
| 区分Riemann 曲面与复曲面、极小子流形与代数曲面的极小模型、联络与连接同态、换基与基变换，以及可积性、相容性和辛闭性。 | 相似汉语或共同词根不代表同一个对象、操作或假设。 |
| 辛作用不自动是 Hamilton 作用，局部标准形不自动给出整体等价，形式平方为零不自动等同于已构造坐标或全纯标架；按具体模块核对定义和所需条件。 | 这些结论之间有实质的构造、整体障碍或可积性问题，不能仅凭相近表达互相替代。 |
| 引入异文献约定时先转为本项目约定再核对公式，不从相反约定中拼接曲率、热方程或 Floer 指数；其他通行约定本身不作为数学错误。 | 真正需要一致的是同一论证内部的定义与推导，方向差异必须经过转换才能比较。 |
| 新增或更改重要用语时，在本文件相应条目保留主称、原文、定义范围、必要异名、依据和证据范围，不另写逐次替换记录。 | 后续人员需要理解该选择解决的歧义，当前有效依据比操作经过更有复用价值。 |

### 本项目既有用语

| 既有用语与使用范围 | 原因 |
|---|---|
| “平展”“固有”用于相应概形态射及其性质，逐项核对定义条件；不把概形的固有性与其他对象中同名性质直接等同。 | 相同英文在不同数学对象上可能有不同定义，既有中文主称不能替代条件说明。 |
| “泛性质”“消解”“正合”用于构造、同调与层论中的相应概念，说明存在唯一性、消解对象和正合位置等实际内容。 | 名称必须对应确定结构，不能只靠术语暗示尚未证明的性质。 |
| “结点”“粘合”用于纲要指定的奇点模型及几何、分析构造；说明局部模型、相容关系与适用环境。 | 这些用字已经由纲要确定，模型和构造条件仍需分别说明。 |
| “求值映射”用于映射空间、截面或其他实际对象的取值构造，注明定义域、值域和结构。 | 同名映射可能作用于不同空间，写清对象后才能判断连续性、光滑性或自然性。 |
| “凝聚层”“拟凝聚层”分别注明解析或代数环境、底环层与所需有限性。 | 两种环境的定义与适用定理不完全相同，凝聚性也依赖指定的环层。 |
| 第一卷人名派生术语统一写为“Lie 群、Lie 代数、Lie 括号、Lie 导数”“Riemann 度量、Riemann 曲面”“Euclid 空间、Euclid 度量、非 Euclid 几何”；Hermitian、Jacobian、Hessian 等沿用各自通行派生形式，中文类别词不省略。 | 原文专名便于与文献对应；专名的形式统一不改变数学对象，也不把通行派生词机械还原成人名词根。 |
| 第一卷覆盖上的自同胚统一称“覆盖变换”，其群称“覆盖变换群”；facet 在本卷写作“余维一的面”。联络的 holonomy 按所指对象描述为“环路平行移动变换／群”，叶状结构使用“横截面返回映射芽／群”，几何结构沿用“单值表示／单值群”，均在首次给出外文对照。 | 描述须对应定义，不能把不同对象的 holonomy 全部改成单值；这些描述不宣称为新核定的官方译名。 |
| 第一卷统一使用“Euler 示性数”“几乎复结构”“平行移动”“环路”；一般表示产生“关联丛”，伴随表示产生“伴随丛”。引文定位中的章、节、附录、习题与页等类别词用中文，原题名和实际引语保留原文。 | 稳定主称便于检索并避免把不同对象合并；中文定位与忠于来源可以同时做到。 |

### 共同专题中的易混概念

| 用语与适用范围 | 原因 |
|---|---|
| 偏导数矩阵用 Jacobian，Jacobi 恒等式及相应专名保留 Jacobi；复半双线性型用 Hermitian，Hermite 用于相应人名和专名。 | 这些派生形式已对应不同对象，不能按人名词根机械互换。 |
| holonomic 与 holomorphic 分别处理；前者没有核定中译时按实际定义给出中文描述，并在首次附原文，不译为“全纯”。 | 两词含义不同，误译会改变对象类别。 |
| 余切复形与切复形或导出对偶分别说明底对象、系数和假设。 | 它们通常通过对偶联系，并非同一个复形，对偶识别还可能需要条件。 |
| “有限生成模”“有限长度模”“底集合有限”完整区分；代数的模有限、有限型与整性分别按定义说明。 | 这些有限性约束的是不同对象和生成方式，不能以一个“有限”省去实质条件。 |
| “拟紧”只表达每个开覆盖有有限子覆盖，不附加 Hausdorff 条件。第一卷第4章的一般拓扑约定中，“紧”也仅指这一开覆盖性质；需要 Hausdorff 时明确另列。其他几何范畴按对象的首次定义核对，不由代数学项目的局部约定统一覆盖。 | 概形、一般拓扑空间与流形的对象假设不同，机械添加分离条件会改变论证范围；记录已经采用的约定便于后续章节准确调用。 |
| 第一卷第4章的“正则”“正规”均包含 T1 条件；“仿紧”只要求每个开覆盖有局部有限开细化，不自带 Hausdorff 条件。 | 文献的命名约定并不完全一致；明确分离条件可防止后文把仿紧性单独当作正规性或单位分解的充分条件。 |
| 第一卷第5章规定道路拼接 \(\alpha*\beta\) 先走 \(\alpha\) 后走 \(\beta\)，基本群乘法采用这一顺序；纤维的单值作用为右作用，万有覆盖的道路类模型以前置环路给出左覆盖变换作用，函数复合仍按通常顺序。覆盖的“叶数”指纤维基数，允许无限；“适当不连续”采用每一点有邻域 \(U\)，使 \(gU\cap U=\varnothing\) 对所有非单位群元素 \(g\) 成立的强定义。 | 拼接、函数复合及左右作用混用会倒转乘法或误得反群；叶数与叶状结构、不同文献的适当不连续条件也存在术语歧义，明确本章约定才能正确调用覆盖与商空间结论。 |
| 第一卷第6章的“拓扑曲面”默认 Hausdorff、第二可数，允许边界；“闭曲面”表示紧且无边界。标准模型记为 \(\Sigma_{g,b}\) 和 \(N_{k,b}\)，分别记录可定向模型的手柄数、不可定向模型的交叉帽数及边界分支数，其中 \(\Sigma_{0,0}=S^2\)。不可定向曲面的本质简单闭曲线除不围圆盘、不与边界平行外，还要求不围 Möbius 带。公共细分的结论使用“先作环境同痕、再取有限公共细分”，不声称任意两个原始拓扑剖分直接存在有限公共细分。 | 曲面的分离与可数条件、闭性的含义、两类模型的参数及本质曲线的排除范围均影响分类和切割结论；两条拓扑边可能有无限次交叠，漏掉同痕步骤会把有限组合结论误用于原始嵌入。 |
| 第一卷第7章一般参数的导数用点号，弧长参数的导数用撇号；空间曲率记为 \(\kappa\geq0\)，平面有向曲率记为 \(k\)，Frenet 标架在 \(\kappa>0\) 的区间上采用 \(\tau=-\langle B',N\rangle\)。空间曲线反向参数化不改变挠率，环境反射使挠率变号。\(C^r\) 正则闭曲线指 \(\mathbb R/P\mathbb Z\) 上的 \(C^r\) 正则参数曲线，其中 \(P>0\)；用闭区间表示时，位置及直到 \(r\) 阶的导数须在两端匹配。平行法标架在参数区间上存在，不自动保证绕一周后仍为周期标架。 | 导数所用参数、平面与空间曲率的符号以及环境定向会改变计算公式；仅有端点位置相同或区间上的标架存在，不能推出闭合处的正则性与标架相容。明确这些约定可防止重参数化、镜像和闭合问题中漏掉条件。 |
| 第一卷第8章使用光滑（\(C^\infty\)）浸入，记 \(X_i=\partial_iX\)、\(g_{ij}=\langle X_i,X_j\rangle\)，第一基本形式记为 \(I\)。取选定单位法向 \(n\)，规定 \(S=-\mathrm{d}n\)、\(h_{ij}=\langle X_{ij},n\rangle\)、\(\mathrm{II}(V,W)=\langle SV,W\rangle\)、\(H=\operatorname{tr}S/2\)、\(K=\det S\)；故外向法向的半径 \(R\) 球面主曲率为 \(-1/R\)，而 \(K=1/R^2\)。非负 Laplace 算子用 \(\Delta=-\operatorname{div}\operatorname{grad}\)；曲率符号沿用下文统一约定，分量按 \(R(X_1,X_2)X_j=R^k{}_{j12}X_k\) 排列。曲面基本定理固定参数对应，以参数叉积选法向，唯一性中的刚性变换保持定向；局部存在与整体单值分别判断。 | 法向、平均曲率归一化、微分算子正负号和曲率指标次序会改变公式；参数对应与法向选择决定唯一性的含义，局部相容也不能自行消除绕环路后的标架或位置障碍。这些约定使后续计算与实现问题能够准确调用本章。 |
| 第一卷第9章在定向度量曲面上以 \(J\) 表示正向旋转 \(\pi/2\)，嵌入曲面取 \(JV=n\times V\)。对正向正交单位标架 \((e_1,e_2)\)，取 \(\omega(V)=\langle\nabla_Ve_1,e_2\rangle\)，故 \(\nabla e_1=\omega e_2\)、\(\mathrm{d}\omega=-K\,\mathrm{d}A\)。单位速曲线的有向测地曲率为 \(k_g=\langle \mathrm{D}_sT,JT\rangle\)；正向边界使区域在左，内角为 \(\beta\) 时有向外角为 \(\alpha=\pi-\beta\)。环路平行移动的旋转角按模 \(2\pi\) 理解，实数角提升须另说明选择。共形变化等公式继续使用非负 Laplace 算子 \(\Delta=-\operatorname{div}\operatorname{grad}\)。 | 标架次序、边界方向、外角和 Laplace 符号共同决定曲率积分及变分公式的正负号；环路平行移动只确定旋转而不自动确定一个实数角。固定这些约定可防止局部公式、公共边抵消和整体 Gauss–Bonnet 结论之间出现符号漂移。 |
| 第一卷第10章的双曲模型统一取曲率 \(-1\)，双曲面采用 \(\langle x,y\rangle_L=-x_0y_0+x_1y_1+x_2y_2\)；上半平面与圆盘的度量分别为 \(\lvert\mathrm{d}z\rvert^2/(\operatorname{Im}z)^2\) 与 \(4\lvert\mathrm{d}w\rvert^2/(1-\lvert w\rvert^2)^2\)。\(\operatorname{PSL}(2,\mathbb R)\) 中矩阵 \(A\) 与 \(-A\) 表示同一变换，分类用迹平方。离散群的“固有作用”采用紧集相交判据，允许有限稳定子；与自由性合用才得到第五章的强适当不连续条件。几何结构的单值表示作用于模型，须与第九章切平面上的联络的环路平行移动 区分；展开映射使用第五章前置环路的左覆盖变换作用，\(\rho\) 按同一乘法顺序为同态。 | 曲率归一化影响长度、面积及三角公式；矩阵代表、自由性与固有性决定分类和商空间是否光滑。结构单值与联络单值比较的是不同对象，左右作用混用也会颠倒表示的乘法，因而需要保留这些具体约定。 |
| 第一卷第11章用局部光滑函数芽上的导子定义切空间；边界模型为最后坐标非负的半空间，光滑性指局部光滑延拓。边界点的完整切空间仍为流形维数，双侧曲线速度为边界切空间，单侧右速度为内向切锥。微分记为 \(\mathrm{d}F_p\)，余切拉回为其对偶 \((\mathrm{d}F_p)^*\)。 | 导子定义不依赖尚未建立的单位分解；边界处三种速度集合不同，混同会使维数及满秩条件出错。明确拉回方向也可避免把切向量与协变向量的变换公式混用。 |
| 第一卷第11章的嵌入要求浸入且为到子空间像的同胚；固有映射指紧集的原像紧，与第10章固有群作用分别按对象判断。neat submanifold 用“与边界相容的横截嵌入子流形”描述，首次附英文对照，定义为带边界嵌入子流形满足自身边界等于与环境边界的交，并与环境边界横截；此描述不宣称为已核定的通行译名。 | 单射或闭像不能代替嵌入的拓扑条件；边界水平集还需边界限制满秩。保留明确的定义与英文便于后续核对文献中的边界约定，也防止同名固有性混用。 |
| 局部分支与全局不可约分量分别定义；“正规”“正则”“光滑”及相应态射性质写明适用对象。 | 局部模型不直接确定全局分解，相似名称也不能代替不同环境中的定义。 |
| 第一卷第12章固定行标架约定 \(e_j=e_i g_{ij}\)，同一向量分量满足 \(v_i=g_{ij}v_j\)，余循环为 \(g_{ij}g_{jk}=g_{ik}\)；标架 \(u:\mathbb R^r\to E_p\) 的右作用为 \(u\cdot A=u\circ A\)。\(T^r_s\) 的上标计向量因子、下标计对偶因子，实际求值输入分别是 \(r\) 个协变向量与 \(s\) 个向量。 | 标架、分量及左右作用的变换方向不同；固定次序可避免粘合公式、张量变换和后续联络公式互相倒置。 |

| 第一卷附录 E 固定 Cartan 矩阵约定 \(a_{ij}=2\langle\alpha_i,\alpha_j\rangle/\lVert\alpha_i\rVert^2\)，分母属于行指标 \(i\)，故 \(s_i\alpha_j=\alpha_j-a_{ij}\alpha_i\)；Dynkin 图重边的箭头指向短根。 | 文献也有转置约定；明确分母、反射公式与箭头方向，可避免长短根、矩阵和图的数据互相倒置。 |
| 第一卷附录 E 的凸正多胞形以其仿射包络中的全 Euclid 等距对称群在完整面旗上传递为定义，群中允许反射；顶点传递或各面全等不能代替旗传递。 | 这些对称条件的强度不同，组合对称也不自动由 Euclid 等距变换实现；旗传递是本附录分类与反射室论证的实际假设。 |
| 第一卷附录 E 的内二面角沿棱取垂直截面，使用材料内部的截面角；凸块的该角在 \((0,\pi)\)，与相邻两面外法向量的夹角互补。 | 两种角相差一个补角，会改变刚性计算及 Dehn 不变量的公式；凸块的角度范围也不能直接套用于一般非凸材料。 |
| 第一卷附录 E 的 Dehn 不变量取值于 \(\mathbb R\otimes_{\mathbb Q}(\mathbb R/(\pi\mathbb Q))\)，两因子分别记录实棱长与内二面角的类，张量积在 \(\mathbb Q\) 上构造。剪刀合同使用有限多面体剖分，逐块等距变换允许反射。 | 张量基域和角商决定有理倍 \(\pi\) 的角类消失及切割项抵消的方式；剖分是否有限、运动是否允许反射也决定分类结果的适用范围。 |
| 第二卷第1章的道路拼接 \(\alpha*\beta\) 先走 \(\alpha\) 后走 \(\beta\)，纤维单值为右作用，道路类万有覆盖以前置环路给出左覆盖变换，函数复合仍按通常顺序。映射柱把源端放在 \(t=0\)，在 \(t=1\) 粘到靶空间。附着记号 \(Y\cup_fX\) 用于 \(A\subset X\)、\(f:A\to Y\)，将靶空间 \(Y\) 写在左边。余纤维化按一般映射的同伦延拓性质定义；NDR 判据用于闭子空间包含。CW 复形采用逐维附着的弱拓扑，不默认局部有限。 | 拼接与作用的方向决定覆盖变换公式；柱参数及附着记号的次序决定粘合与同伦公式；闭性及弱拓扑分别影响延拓判据和无限胞腔的连续性，不能在后续调用中省去。 |
| 第二卷第2章默认整数系数。链微分 \(\mathrm{d}\) 降低一次，链同伦满足 \(g-f=\mathrm{d}H+H\mathrm{d}\)；对链映射 \(f:C\to D\)，映射锥取 \(\operatorname{Cone}(f)_n=D_n\oplus C_{n-1}\)，微分为 \((y,x)\mapsto(\mathrm{d}_Dy+f(x),-\mathrm{d}_Cx)\)。约化奇异链在 \(-1\) 次取 \(\mathbb Z\)，零次边界为增广，故 \(\widetilde H_{-1}(\varnothing)=\mathbb Z\)。短正合列的连接同态按 \(p(b)=c\)、\(\mathrm{d}b=i(a)\) 取 \(\delta[c]=[a]\)；Mayer–Vietoris 序列的第一映射为 \((i_*,-j_*)\)，第二映射求和，对小圈 \(z=a+b\) 取 \(\delta[z]=[\partial a]\)。 | 微分、移位和连接同态的符号共同决定长正合列与代表链的计算；保留空集的负一次约化同调，才能正确处理空交集及低维末端。 |
| 第二卷第3章取 \(C_n^{\mathrm{cell}}(X)=H_n(X^n,X^{n-1};\mathbb Z)\)，胞腔微分为连接映射后接相对化，即 \(\mathrm{d}_n=j_{n-1}\delta_n\)。胞腔定向指相对圆盘生成元，边界球面定向由连接同态传递；边界矩阵以源胞腔的像为列。透镜空间固定 \(L(p,q)=S^3/((z_1,z_2)\sim(\zeta z_1,\zeta^qz_2))\)，其中 \(\zeta=e^{2\pi\mathrm{i}/p}\)、\(p\ge2\)、\(\gcd(p,q)=1\)。 | 连接映射、球面定向与矩阵列约定共同决定边界系数的符号；透镜空间的第二参数在其他粘合约定中可能换成模逆，后续计算须能恢复当前采用的模型。 |

光滑流形默认有限维、Hausdorff 且第二可数；紧性、完备性、边界和定向另列。概形不默认约化、不可约、正规或光滑；基域、特征、有限性及几何纤维的条件逐项注明。实维数、复维数和相对维数分别使用。中文主称沿用本项目的“平展、固有、泛性质、消解、正合”；必要时在首次定义并列原文，不以未经核验的译名替换已有术语。

曲率约定为

$$
R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z,
\qquad
K(X,Y)=\frac{\langle R(X,Y)Y,X\rangle}{|X|^2|Y|^2-\langle X,Y\rangle^2}.
$$

标准球面的截面曲率为正。非负 Laplace 算子取 $\Delta=\mathrm{d}^*\mathrm{d}=-\operatorname{div}\nabla$，形式上取 $\mathrm{d}\mathrm{d}^*+\mathrm{d}^*\mathrm{d}$，热方程为 $\partial_tu=-\Delta u$。

辛几何采用

$$
\theta=\sum_i p_i\,\mathrm{d}q^i,\qquad \omega=-\mathrm{d}\theta=\sum_i \mathrm{d}q^i\wedge\mathrm{d}p_i,
\qquad \iota_{X_H}\omega=\mathrm{d}H,
$$

以及相容约定 $g(u,v)=\omega(u,Jv)$、$J^2=-1$、$\omega(Ju,Jv)=\omega(u,v)$，其中 $g$ 正定。Kähler 情形再要求 $J$ 可积及 $\mathrm{d}\omega=0$。

在第四卷所选可缩轨道模块中，封口圆盘的边界按轨道的正向参数给定，采用

$$
\mathcal A_H([x,u])=-\int_{D^2}u^*\omega-\int_0^1 H_t(x(t))\,\mathrm{d}t.
$$

由上述约定直接计算梯度，取负梯度方程

$$
\partial_su+J_t(u)(\partial_tu-X_{H_t}(u))=0,
\qquad
E(u)=\mathcal A_H(x_-)-\mathcal A_H(x_+)
$$

（能量公式此处指固定数据的轨线；延拓方程另有参数变化项）。常值环上 $\mathcal A_H=-H$，小自主 Hamilton 与 Morse 复形的比较因此使用 $-H$。轨道指数的规范随此选择核验，不从不同文献拼接相反符号。

链、上链、复形移位及张量总微分在各卷首次使用时明确。解析与代数 Riemann–Roch、有限维 Sard 与 Sard–Smale、二维与高维 Gauss–Bonnet 分别注明版本；Riemann 曲面、复曲面、极小子流形和代数曲面的极小模型分别命名。
