# 《几何学》写作规范

本规范管理内容组织与证明质量，也是同目录五份规范的共同总则。术语、排版、书目和操作分别见《术语规范》《格式规范》《书目维护注意事项》和《工作流程说明》；目录与证明范围以根目录 [几何学计划纲要](../几何学计划纲要.md) 为依据。

## 总则

| 规则与适用范围 | 原因 |
|---|---|
| 五份规范的每一条要求都写明适用范围与实际原因；新增或修改要求时一并说明它解决的具体问题，不以“保持规范”作为唯一理由。 | 原因使后续人员能够判断要求是否必要、何时适用，避免把临时处理办法固化成没有用途的义务。 |
| 规则的原因不再成立时，该规则在原因失效的范围内立即失效，并及时删改；不得借历史惯例继续要求。若另有仍然有效的理由，须据此明确重写规则与范围。 | 规则服务于实际工作；环境或需求改变后，旧理由不能继续承担约束依据，新理由也需要接受独立判断。 |
| 同一事项只在主管文件完整维护，其他文件按需链接；本节是共同总则的唯一完整维护处。 | 多处抄写同一规则容易产生不一致，使后续人员无法判断哪个版本有效。 |
| 用户当前指令优先于本项目规范；结合已有指令判断授权，已经明确授权的同一事项不重复询问。 | 规范用于落实作者意图，不能反过来阻碍已明确的工作或产生无意义的确认。 |
| 工作记录只为后续接续、定位、核验或决策服务，保留当前状态、可操作的未决问题、必要依据和下一步；每项记录应能说明将在什么后续工作中使用。 | 记录的价值是减少后续重复查找和判断，而不是证明曾经忙碌。 |
| 不产生逐次执行、编译、渲染或哈希的流水账；只有复现问题、比较版本或作出具体决策所需的结果与环境才作适量记录，后续已无用途时合并或删除。 | 工具输出和时间顺序本身通常不能帮助继续写作，堆积会掩盖当前问题并增加维护负担。 |

## 读者与组织

| 规则与适用范围 | 原因 |
|---|---|
| 读者设定为数学系本科生或研究生，正在首次或第二次系统学习当前知识；可按各卷阅读条件具备基本分析、几何与数理基础，但不预设其为相关领域专家，也不预设其已理解概念的动机、熟练掌握所有技巧或记住前卷全部细节。 | 有一定基础、曾经学过与能够独立恢复每一步推理并不相同；多卷学习还会发生遗忘，讲解须适应该读者的实际理解和记忆。 |
| 按纲要为各卷确定阅读条件，具体说明所需定义和结果。第一卷允许从光滑流形直接学习，第四卷保留复与辛的分别学习方式；不自行加入必须依次通读全部前卷的限制。 | 几何纲要已经安排不同学习起点，统一增加阅读门槛会改变原有教学设计。 |
| 保留固定章号、章题、节题及选读标记。正文采用“卷—编—章—节—小节”，纲要条目作为小节承载构造、证明阶段和算例；附录主题组和组内要点分别作为节、小节。编号及目录层级按《格式规范》执行。改变多章安排或主干与选读边界时先向作者说明方案；已有明确授权的调整按授权执行。 | 保留纲要的教学次序和选读边界，同时用可查的小节编号帮助读者定位及跨章引用；局部写作不能暗中重设全书结构。 |
| 纲要中的节内条目作为编号小节标题列入稿件和目录，各未写内容明确写“待撰写”。节内说明段仍作写作要求保留，不将整段说明机械改成标题。 | 标题和编号帮助读者查找实际内容，并与前作的阅读方式一致；显式占位能防止误认内容已经完成，说明段则保留标题无法表达的要求。 |
| 每编导读说明各章的问题、关系和实际所需基础；直接依赖图只画证明中实际使用且已经核对的关系。 | 导读帮助读者建立数学联系，按章号串联或预想的依赖图会误导阅读。 |
| 一章通常依次安排摘要、学习目标、章首正文、各节、小结和习题。摘要概括问题、内容与所得结果，目标写可执行任务；骨架可以保留栏目，但不得用占位文字宣称已写完。 | 各栏目分别承担概括、提出任务、展开和收束的职责，栏目齐全不能代表内容齐全。 |
| 目标之后的章首正文须能独立作为文章开头：由具体问题、例子或计算展开缘由与思路，再交代真正需要的基础、可暂缓的内容和参考资料，不逐字复述摘要。 | 读者可能跳过摘要；若正文只剩基础与书目说明，整章将缺少数学引入。 |
| 每个设有小节的节，在节标题与首个小节之间写说明文字，提出眼前问题、说明所用对象或联系前文；不把标题换一种说法再列一遍，也不把普通内容顺序写成操作步骤。 | 读者需要本节的数学上下文，标题和先后次序本身不能说明问题为何产生。 |
| 小结收束所得结果与方法，结束后直接进入习题；其他正文、表格和阅读说明放在小结之前，做题建议可放在习题标题之后。 | 小结应结束正文，习题应有清楚的阅读起点。 |
| 定义先交代对象、环境、局部符号与条件，再命名；基础概念先于使用它的构造。新概念由问题、计算或具体构造引入，说明它要解决什么问题、关键条件有什么作用，随后给出可核验的例子、边界情形或反例；不凭作者熟悉就省去引入缘由，也不为凑动机虚构历史或失败过程。 | 定义的形式正确不等于读者明白为何需要它；问题与条件的联系帮助理解，完整假设和真实依赖次序则防止误用与循环理解。 |
| 本书按可独立阅读的教材写作，各节按任务交代背景、定义、主要结果、关键论证与代表性算例，不写成名词和结论目录。 | 教材需要帮助读者重建推理，仅列结果不能完成这一教学任务。 |
| 标题用具体的对象、方法或问题；篇幅、题数和段落长度随内容而定。保留已有提纲文字时明确其任务性质，不把规划冒充成稿。 | 数学主题需要的论证不同，形式整齐或页数指标不能反映内容密度与完成度。 |
| 序言如实说明写作目的、范围、读者、预备知识、篇章安排、使用方法与资料层次；缘起、致谢和成稿信息只写能够核实的内容。 | 序言建立阅读预期，虚构的成书叙事会使读者误判作品背景与状态。 |
| 后记回望全书取舍、未展开内容和进一步阅读，不重复序言；所引诗文或其他材料与主题有可说明的联系并保留出处。 | 后记承担收束与展望的职责，无关引文和重复说明不能增加阅读价值。 |
| 已有实质正文的附录也按实际内容给出摘要、目标、所需基础与小结；纯阅读建议不单独占用编号节，不以短篇附录声称完整覆盖一个领域。 | 附录仍需可读，但形式栏目与空节不能制造理论已经展开的错觉。 |

## 陈述与证明

| 规则与适用范围 | 原因 |
|---|---|
| 定理、命题、引理、推论和正式断言须能独立阅读，在陈述内明确对象、维数、基域、特征、有限性、正则性、紧性、完备性、边界、定向及实际需要的其他条件，不只依赖节首约定。 | 正式结果常被单独检索或引用，缺少上下文时仍须能够准确判断适用范围。 |
| 重要条件须在证明或结论中有可解释的作用，按主题用失败机制、边界情形或反例说明其必要性。 | 读者需要知道删除条件会发生什么，才能理解结论的边界。 |
| 每个构造先说明目标、为何这样选择对象或操作、关键步骤解决什么障碍，再按实际需要交代输入、选择、良定义、所需公理、映射相容性、泛性质与唯一性的含义；商、粘合、下降、模空间及不变量尤其不能略去等价关系、相容性或选择无关性。 | 读者不仅需要检查构造成立，还需要理解如何想到并使用它；只给完成后的形式容易隐藏选择的缘由，遗漏实质步骤又会留下数学缺口。 |
| 每章开头的“目标与证明范围”是写作任务。承诺完整证明的结果必须落实证明，不因标星就自动降为名称介绍或外部引用。 | 选读标记表示阅读范围，不能取消纲要已经承担的证明责任。 |
| 使用分析、拓扑、代数或其他背景知识时，对当前理解必需而不能合理预设熟练的概念、结论含义和用法作适量提醒；调用外部结果注明精确版本、假设、所用结论、来源与证明位置，较长背景给出可直接查找的注释或引文。回顾以当前问题为界，不扩写整套外部课程；证明概要另说明省略的技术内容和依据。 | 本书读者有基础但未必精通相关学科；只报名称或出处仍可能无法理解当前步骤，重写整套理论又会淹没几何主题。同名定理还可能有不同版本，需要明确调用边界。 |
| 严格区分局部与整体、光滑与弱解、存在与唯一性、紧性与正则性、泛型与指定数据，以及几何对象与其参数或商。有限阶计算和典型算例不代替一般证明。 | 这些区别改变结论的内容和量词，不能由局部模型或计算证据自动跨越。 |
| 核对依赖时实际阅读被调用结果的陈述与证明，确认假设、方向和版本一致；不得以尚未写成的后文、未来附录或习题暗中承担当前证明。 | 引用能解析或定理名称相同，都不能排除条件不符和循环依赖。 |
| 调用前章或前卷结果时，给出明确的结果编号或可查位置，并按当前用途简要恢复所需结论、关键条件和记号，说明当前对象如何对应、假设为何满足以及得到什么；对象对应、相容条件、核与像、参数或穷尽依据按当前问题补明，必要的短等式也不省略，不只写“由前文”或以“显然”“trivial”带过。 | 读者可能记得核心结论或著名定理，却忘记技术条件、局部记号和具体证明细节；就近唤回实际所需内容可减少回翻，并防止条件在调用中丢失。 |
| 调用已证结果通常不重抄整段旧证明，但允许为当前难点重述必要的局部论证或短算例；同一证明内紧邻、已经说明且指代唯一的步骤可以直接承接，基本算术不为凑引用添加回链。 | 必要回顾能帮助读者重新接上推理，整段重复却可能遮住新步骤；是否补充取决于实际理解障碍，不能把避免重复变成拒绝解释。 |
| 每个结果原则上只有一个主要证明位置；其他位置可应用或给出明确标示的第二证明，不暗改条件与约定。后文反复使用而先前只藏在某段证明中的结论，应提升为边界清楚、可准确定位的正式结果。 | 稳定的陈述和证明位置有助于复用，避免卷间版本漂移或要求读者寻找隐含步骤。 |
| 提前陈述和延迟证明写明具体对应结果及证明位置；正文只交代必要条件、缺口和去向，不逐处声明“这里不调用后文”“只作前瞻”等内部检查。 | 读者需要可查的证明承诺；防御性说明既打断叙述，也不能代替依赖核对。 |
| 正文可用附录提供例子、动机和阅读建议，但不得无说明地依赖附录；选读内容若成为主干必需前提，应按作者认可的范围重新确定位置。 | 选读边界只有在跳过相应内容后主干仍然自足时才有意义。 |
| “由标准理论”“取适当坐标”“容易验证”等措辞只用于目标读者在当前上下文中能够恢复的机械步骤，不能按作者的专家熟练度判断；良定义、符号、极限、边界项、紧性、整性、横截性和粘合等实质环节必须展开或准确引用，并补足理解调用所需的解释。 | 作者觉得熟悉的跳步可能正是初学读者的障碍，准确引用也不自动说明当前步骤如何得到；简略措辞不能掩盖数学缺口或教学缺口。 |
| 较长或构造性证明在细节前或证明开头说明目标、主要想法和关键障碍，在转折处交代下一步为何有用；思路说明与随后的完整证明对应，不用概述替代证明。 | 读者可能能检查单个等式，却看不出为何这样推进；先说明路线有助于把局部步骤组织成可理解的论证。 |
| 一个完整证明尽量放在同一 `proof` 环境中，不拆成“证明（续）”“证明（完）”；长证明或多项等价条件用自然段或少量有内容的阶段组织。 | 清楚的环境边界和分阶段结构可以防止漏证，也避免读者误认中间段已经结束。 |

## 数学环境的语义

| 环境与使用范围 | 原因 |
|---|---|
| `definition` 精确引入概念、结构或局部约定。 | 定义确定对象与量词，需要与解释性文字区分。 |
| `theorem` 陈述章节或理论的核心结果；`proposition` 陈述普通结论或基本性质；`lemma` 陈述主要服务于后续证明的工具结论。 | 环境层级应帮助读者理解目标与工具的关系，而不是表示版面强调程度。 |
| `claim` 承载证明中的局部断言；`corollary` 承载已证结果经短推导得到的直接后果。 | 局部步骤与直接后果有不同的论证职责，不宜全部包装成新的主定理。 |
| `remark` 用于必要辨析、限制和提醒；需要独立回引的构造或算例使用 `example`，短例通常融入正文。 | 正式环境只在便于理解和定位时使用，避免把动机和普通过渡切碎。 |
| `conjecture`、`openproblem` 分别陈述明确未证明的猜想和尚未解决的问题。 | 显式标明未知状态能防止读者将研究问题误认为本书结论。 |
| `exercise`、`optionalexercise` 分别承载常规练习与确属选做的练习；`proof`、`solution` 分别给出完整证明与完整解答。 | 阅读范围与论证完整程度需要明确区别。 |
| `proofsketch` 只作明确的证明概要，写出省略的技术内容、所用输入与依据。 | 读者知道缺少什么及到哪里补足后，概要才是可用的教学材料。 |
| 环境类型不能代替证明状态，不用于包装普通动机、过渡句或修辞强调；具名结果只采用有依据的通行名称。 | 数学职责、证明状态与历史归属是不同信息，混用会误导读者。 |

## 例子、习题与图形

| 规则与适用范围 | 原因 |
|---|---|
| 每章安排能够计算、构造或核验的代表例子，并按主题加入边界情形或反例；重复模型每次增加新的观察，写明当前工作环、基域、特征或其他会改变含义的条件。 | 例子应检验理论的适用范围，同一公式在不同环境下可能失效。 |
| 算法内容写明输入、输出、适用条件、工作对象与可执行步骤；存在性、可计算性和复杂度分别论证。 | 对象存在不等于已经给出算法，算法有效也不自动具有某个复杂度界。 |
| 习题训练正文提供的概念与方法，不把主干证明或关键讲解思路留在习题。需将习题中的关键结论提升到正文时，向作者说明具体调整，并保留考察原知识点且任务有实质变化的练习；已有授权按授权执行。 | 读者可能跳过习题，正文的证明责任不能由练习承担，补全正文后也仍需训练相应知识点。 |
| 习题覆盖主要概念、构造、结果与方法，依任务配置基础核验、计算、构造、反例、综合证明等题型，不设统一数量。 | 不同任务需要不同练习，固定配额会造成重复或遗漏。 |
| 习题不原样复述正文已证命题，应改变实质条件、提出新构造或反例、连接不同工具，或补充不影响正文完整性的推导。 | 练习应要求新的判断，而不是抄写正文。 |
| 每题给出完整解答或明确标示的提示，不只写“同正文”；依赖选读内容的整题或个别小问按实际范围标星。 | 读者需要可检查的反馈，并准确知道哪部分超出常规阅读范围。 |
| 取材于教材、竞赛题或专业论坛时，保留来源、改编范围和必要的许可信息，具体按书目与版权要求处理。 | 改写本身不能替代来源说明，也不自动消除原材料的署名和许可条件。 |
| 几何关系、映射、变分、局部模型、构造选择或证明思路用简明图示更容易理解时，主动配图并在正文说明图中对象与符号对应什么、直观揭示了什么；直观解释与完整严谨的证明相互配合，不因要求严谨就省去有帮助的图示，也不让图示替代假设和论证或暗示未经证明的嵌入、唯一性与尺度关系。 | 图示能显露长段文字难以直观呈现的结构，完整证明负责落实结论和适用范围；二者对应可同时帮助理解与核验。 |
| 重要泛性质首次引入时配规定映射、测试对象与唯一分解的交换图；自然性、伴随、长正合列和图引理的关键构造按需要配图。箭头注明所保持的结构，同伦意义下的唯一性另行说明。 | 这类构造以映射及相容关系为核心，图应准确显示正文要核对的关系。 |
| 多个对象、条件、结论或边界情形用表格更容易比较时配表，不用冗长文字反复罗列相同维度；图表随相应定义或证明排放，正文解释比较结果，并核对对象、箭头、包含关系、条件和结论，不要求每节机械配齐图表。 | 合适的图表能减轻记忆负担并显出差异，错误或无实际用途的图表则会强化误解或增加阅读负担。 |

## 行文与质量状态

| 规则与适用范围 | 原因 |
|---|---|
| 用自然、准确的中文叙述对象和推理。定义按中文语序先交代对象及条件，再命名，避免“称……，如果……”等倒置表达；条件、原因、长定语和指代的安排须使主谓关系及逻辑范围清楚。不以“入口、接口、主线”等规划词代替具体数学内容，阅读条件写明所需章节与结果。 | 符合中文习惯的语序便于读者辨明条件与结论，避免修饰错位和指代歧义；读者也需要知道讨论什么及实际依赖什么，抽象编写用语不能提供这些信息。 |
| 写作与审读时按上述读者的知识和遗忘情况逐段追问：概念为何提出、构造为何这样做、旧结果如何用于此处、哪一步推理或语言可能接不上、图表能否更清楚。发现障碍须定位到具体文字或步骤，能补足的在原处补足，未解决的在反馈中写明困惑及所需说明，不只笼统评价“难懂”或“缺少直观”。 | 数学上无误的文字仍可能缺乏可学习的解释；定位真实卡点才能有针对性地修改，而不是降低严谨性或堆积泛泛建议。 |
| 保留有确定意义的数学术语，不设机械禁词表，不按词频批量替换；句长与段落长度服从数学任务，不把所有小节压成等长摘要。 | 同一词在不同语境中的合理性不同，机械整齐会损害准确性和论证节奏。 |
| 已有星号的章、节或小节不在正文、图表和习题引言反复加“选读”标签；不用“进阶”“高级”等人为分级代替具体内容与知识条件。 | 重复标签会干扰阅读，模糊的层级名称不能说明真实的学习要求。 |
| 按[反防御性写作](https://github.com/Kiterlin/anti-defensive-writing/blob/main/SKILL.md)的功能判断修订正文，结合相邻论证逐处审读章、节首尾、小节起首及定理之间的连接文字。说明已得结果如何引出当前问题、下一构造为何需要，范围写成具体条件；删去重复免责、面向假想质疑的辩解及“上述论证完整”等自我验收语，不把这些句子换成只排列标题的空泛过渡。必要的定理假设、概念对比、反例、符号约定、外部输入与待证位置在陈述或实际使用处清楚保留，按已有证据和证明状态措辞。 | 这些衔接处决定读者能否把各个结果连成论证，仅检索措辞容易遗漏其数学职责。直接说明对象与承接关系有助于理解，重复自辩则打断论述；必要限定决定结论能否成立与如何使用，删去、移远或将充分条件写成必要条件都会损害数学准确性。 |
| 中文句子中的公式与外文承担清楚的语法成分，不把公式与英文形容词直接拼成中文谓语；术语与记号按《术语规范》维护。 | 清楚的句法减少歧义，单一术语来源防止卷间暗换名称和约定。 |
| 数学史、人物归属与引语以原著、可靠研究或可核查记述为依据；区分史实中的研究动机与本书教学引入，不虚构心理、对话和发现经过。正文叙述与文献实际用语分别处理。 | 数学上自然的推导不等于真实历史，来源须支持写出的具体归属。 |
| 正文中的数学史只保留有助于理解问题、思想或方法的内容；引语来源、转述链条和人物事迹的考据放在相应脚注。 | 考据应便于核查，也应避免打断数学叙述。 |
| 跨卷调用写明真实目标卷、位置、结果、所需内容及证明状态，区分已证调用、前瞻陈述与计划位置；按上文调用旧结果的要求唤回当前必需的条件、记号和用法，不因“前卷学过”省略理解所需的衔接，也不为避免引用而重写整套理论。 | 分卷与出版次序不能隐藏前提，时间间隔还会造成遗忘；必要回顾帮助理解，过度重复又会造成版本漂移。 |
| 完成度以本节任务所需的解释、证明链、算例和习题为依据；章首范围、目录、占位文字、页数与字数均不证明任务已经完成。 | 形式指标容易掩盖数学缺口，不能代表教学任务已经落实。 |
| 骨架、初稿、正式审核、定稿、编译通过和 Git 状态分别如实表述。正式审核需要完整可检查的陈述、证明、例子与习题，未解决疑点保留为具体问题。 | 文件存在、数学写成、数学经过审查、输出可用与版本保存分别回答不同问题。 |
| 初稿阶段的必要自检不自动算作正式审稿，“尚未审稿”也不能成为省略主干论证或关键条件的理由。 | 写作与审稿各有责任，二者不能相互替代。 |
